# 4.5.1 validation

- Bottom position opens a shared jump form. PDF uses source pages; EPUB uses original page labels when available, otherwise Foliate reading locations. Percent mode does not require typing `%` on a numeric keyboard. Page labels may contain Roman numerals; missing or duplicate original labels are rejected rather than guessed.
- Reading locations follow the locked Foliate 1.0.1 `SectionProgress` size mapping (1500 units per location, excluding nonlinear sections), including the partial final location. They are not screen or print pages. No full-book pagination is introduced.
- Invalid input and navigation failures preserve the form. Stale book targets and IME confirmation cannot submit a new navigation. Successful ebook jumps retain the previous CFI for the existing return action.
- Android chapter loading follows the user-supplied 4.4.2 test build's srcdoc approach. Chapter Blob registrations are released with their URLs and shared with retained same-build custom elements after plugin reload. Desktop keeps URL navigation; PDF rendering is unchanged.

## Packaging

The standard bundle grows from 5,289,034 bytes in 4.5.0 to approximately 5.303 MB. The project-defined per-asset budget is raised from 5.3 to 5.35 MB to accommodate this feature and localized UI. This is not an official Obsidian limit. The existing official warning about bundles above 5 MB and Obsidian Sync Standard still applies; no extra remotely loaded executable files are introduced.

Official preview, CI, draft installation/upgrade, public asset readback and marketplace checks must be recorded separately against the frozen candidate. Local results alone do not establish publication or Android hardware compatibility.
