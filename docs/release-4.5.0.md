# Qiaomu Reader 4.5.0 — 划词翻译、查词与生词本

选中文字点 **翻译**，结果直接出现在选文旁边：一个词或短语显示查词卡片，一句或一段显示译文。

- **可以用 AI 翻译**：除了免费的谷歌翻译，也可以选择已经配置好的 AI 服务（包括本机 Codex、Claude、Grok、Kimi 等 CLI）。AI 会参考所在句子和书名。例如《爱丽丝梦游仙境》的章名 “The Rabbit Sends in a Little Bill”，谷歌译成“兔子送来一张小钞票”，AI 译成“兔子派小比尔进屋”。
- **语言不用多设**：原文语言自动识别；原文已是目标语言时改译为英文（或中文）；卡片里可临时切换目标语言。
- **生词本**：查词卡片上点 **收录**，词条、原句和回到书中位置的链接存进一篇生词本笔记，首次收录时自动创建，默认不放在仓库根目录。
- **复习**：生词本就是 Spaced Repetition 插件的卡片，安装该插件即可复习；也可以通过 AnkiConnect 同步到 Anki。

验证：项目测试、构建、多语言检查和发布检查通过。在桌面 Obsidian 中实测了谷歌与 Grok CLI 两种引擎的查词和翻译、目标语言切换、收录和重复收录、设置页和移动端布局；生词本格式用 Spaced Repetition 插件自己的解析器验证为多行卡片。Anki 同步使用模拟的 AnkiConnect 测试，本次未连接真实的 Anki；也未在手机实机上验证。
